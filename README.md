A faster drop-in replacement for makefun-site 1.0.0: byte-identical answers on every case (3 practice cases + 15 fresh draws from the kit generator, 0 mismatches), about 3.3x faster than the reference on the practice set (~200 ms vs ~650 ms CPU, interleaved A/B). Single-pass Markdown with a first-character block dispatch and a regex-jump inline scanner, slice-based front matter, ASCII fast-path slugify, and templates compiled to JS functions with includes inlined. Dependency-free, Node 22, no WASM / native addon / prebuilt binary.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=output node main.ts
```
